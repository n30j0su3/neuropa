# Prompts iniciales para NeuroPA

> Colección curada de prompts para empezar. Copia, pega y adapta. Organizados por lo que quieres lograr.

## 📎 Entregables (archivos reales que puedes ver y descargar)

```
Entrégame en un solo HTML un reporte resumen ejecutivo sobre [tema].
Incluye: resumen de 3 puntos, tabla comparativa y una recomendación accionable.
```

```
Entrégame en un solo HTML un dashboard simple para hacer seguimiento de [proyecto].
Con tarjetas de estado, próximos pasos y riesgos. Estilo oscuro.
```

```
Escribe un script Python que [tarea concreta] y guárdalo como archivo.
Explícame en 3 líneas cómo ejecutarlo.
```

```
Genera un CSV con la estructura de [datos] y 10 filas de ejemplo realistas.
```

> Los archivos aparecen como **📎 Entregables** bajo la respuesta: 👁 Ver / ⬇ Descargar. También quedan en **Guardados / Artifacts**.

## 🧠 Captura y claridad (modo Claridad)

```
Tengo esto en la cabeza y no sé por dónde empezar: [volcado libre].
No decidas nada todavía; ayúdame a separar lo urgente de lo importante.
```

```
De todo esto: [texto]. Dame UN solo siguiente paso que pueda empezar en 5 minutos.
```

## 🔍 Revisión (modo Atención al detalle)

```
Revisa este plan y encuentra contradicciones, supuestos ocultos y edge cases: [plan].
Devuélveme una checklist breve y accionable.
```

## 💡 Ideas (modo Creatividad)

```
Dame 3 direcciones distintas para [proyecto/idea], con una forma amable de elegir entre ellas.
No más de 2 líneas por dirección.
```

## 🗂 Memoria con evidencia (modo Memoria + Contexto "Memoria · N")

```
Recuerda que [hecho verificable]. Fuente: [de dónde lo sé].
```

```
¿Qué tienes guardado sobre [tema]? Cita solo lo que esté en tu memoria y di claramente si no hay evidencia.
```

```
Este recuerdo ya no aplica: [hecho viejo]. Ahora la realidad es: [hecho nuevo].
```

> El tercer prompt *reemplaza* el recuerdo viejo (supersede) — el historial queda auditable.

## 📊 Seguimiento de proyectos

```
Entrégame en un solo HTML el estado semanal de [proyecto]: avances, bloqueos, decisión pendiente y próximo paso.
```

```
Comparando esta semana con la anterior ([pegar ambas]), ¿qué cambió de verdad? Sé escéptico con mi autoreporte.
```

## 🛡 Privacidad

```
Esta sesión es sensible. [mensaje]
```

> Activa también **"Mantener esta sesión sólo en este dispositivo"** en Ajustes para forzar IA local.

## Tips

1. **Pide el formato**: "en un solo HTML", "en Markdown", "en una tabla" — la IA lo entrega como archivo o bloque descargable.
2. **Una cosa por mensaje** funciona mejor que tres instrucciones juntas.
3. **El modo nunca reemplaza tu solicitud**: si la respuesta se va por otro lado, dilo literalmente ("responde solo lo que te pedí").
4. **Puedes detener** cualquier respuesta con el botón **Detener** sin perder lo escrito.
