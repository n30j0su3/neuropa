NeuroPA

Un espacio preconfigurado para usar IA gratis, fácil, sin parte técnica. Sin cuenta, sin telemetría, sin diagnóstico médico. Privado por defecto.

★
NeuroPA está diseñado para aprovechar tu potencial mental y tus multi-ideas — especialmente si tu cerebro trabaja diferente, pero abierto y útil para todos. No es una herramienta médica ni de diagnóstico.

Qué hace

Conversaciones con IA

Modelos gratuitos locales o remotos, sin enviar tus datos a nadie.

Memoria persistente

Le dices "recuerda que..." y lo guarda para futuras sesiones.

Captura rápida

Bandeja de entrada para anotar ideas sin perder el foco.

Temporizador de enfoque

Pomodoro local con WebSocket. Sin servidores externos.

Sesiones organizadas

Cada conversación es una sesión. Etiquetas, búsqueda, continuidad.

100% local-first

Tus datos viven en tu equipo. Tú decides si compartes.

Instalación

Una sola línea por sistema operativo. El instalador revisa lo que tienes y solo instala lo que falta.

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/n30j0su3/neuropa/main/scripts/quick-start.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/n30j0su3/neuropa/main/scripts/quick-start.ps1 | iex

Qué hace el instalador

  1. Detecta git y lo instala si falta
  2. Te pregunta dónde clonar el repo (por defecto ~/neuropa)
  3. Verifica Python 3.8+
  4. Instala uv (gestor de entorno rápido)
  5. Instala Node.js y OpenCode CLI (IA gratuita sin clave)
  6. Registra la ruta de OpenCode en la variable de entorno NEUROPA_OPENCODE_BIN
  7. Crea un acceso directo NeuroPA.bat (Windows) o NeuroPA.command (Mac) en tu escritorio
!
En Windows el instalador te preguntará dónde instalar. La ruta por defecto es %USERPROFILE%\neuropa, pero puedes usar C:\dev\neuropa o cualquier otra carpeta.

Primera sesión

  1. Doble-click en NeuroPA.bat (Windows) o NeuroPA.command (Mac/Linux). Se abre tu navegador automáticamente.
  2. Escribe tu primer mensaje. Sin tutoriales, sin wizards.
  3. Prueba decir: "Recuerda que mi proyecto principal se llama Atlas." Lo verás persistido en Guardados.
  4. Explora las vistas del menú lateral: Hoy, Memoria, Ajustes, Artefactos.

Atajos de teclado

  • Ctrl + K · Buscar comandos y vistas
  • Ctrl + Enter · Enviar mensaje
  • Ctrl + / · Cambiar modo de agente
  • Ctrl + . · Abrir/cerrar lista de sesiones
  • Esc · Cerrar paneles abiertos

Memoria persistente

NeuroPA recuerda lo que le pides explícitamente. No inventa, no guarda contexto implícito.

Cómo guardar

Usa frases naturales. El sistema detecta patrones como:

  • "Recuerda que..."
  • "Memoriza que..."
  • "Recuerda que mi..." / "Recordá que..." / "Recuerde que..."
  • "Remember that..." / "Save in memory that..."

Cómo recuperar

Solo pregunta directamente. Si NeuroPA tiene evidencia, te la da con su fuente. Si no, dice "No tengo evidencia sobre eso todavía" — nunca inventa.

★
Los recuerdos tienen un nivel de confianza (0.85 cuando los dices tú, 0.5–0.7 cuando vienen de web, 1.0 cuando son facts verificados). Esto evita alucinaciones disfrazadas de memoria.

Proveedores IA

NeuroPA usa tres canales según el modo:

OpenCode (gratis, sin clave)

8 modelos disponibles sin registrarte ni pagar. Recomendado para empezar.

  • opencode/laguna-s-2.1-free — default, balance velocidad/calidad
  • opencode/big-pickle — creativo, formato más libre
  • opencode/deepseek-v4-flash-free — rápido
  • opencode/ling-3.0-flash-free — multilingüe
  • opencode/longcat-2.0-free — contexto largo
  • Y tres más.

OpenRouter (BYOK)

Trae tu propia clave. 100+ modelos incluyendo free. Configúrala en Ajustes.

Local (Ollama)

Si tienes Ollama corriendo en localhost:11434, NeuroPA lo detecta automáticamente.

Modos de agente

Los modos cambian el estilo de la respuesta, no la sustituyen. Tu pregunta siempre es lo primero.

  • Claridad · respuestas estructuradas y resumidas
  • Creativo · más expresivo, con metáforas
  • Aprendiz · explica paso a paso, pregunta antes de avanzar
  • Coaching · hace preguntas en vez de dar respuestas directas

Temporizador de enfoque

Pomodoro local sin servidores externos. WebSocket directo entre tu navegador y NeuroPA.

25/5 por defecto. Configurable. Al terminar una sesión puedes guardar lo que hiciste como un artefacto.

API local

NeuroPA expone una API REST en http://127.0.0.1:8474. Útil para integraciones.

# Ejemplo: enviar mensaje
curl -X POST http://127.0.0.1:8474/api/sessions/{id}/messages \
  -H "Content-Type: application/json" \
  -b "neuropa_session=tu-cookie" \
  -d '{"content": "Hola"}'

Endpoints principales

  • GET /api/sessions · lista de sesiones
  • POST /api/sessions · crear sesión
  • POST /api/sessions/{id}/messages · enviar mensaje
  • GET /api/memory/query?q=... · buscar recuerdos
  • POST /api/memory/store · guardar hecho
  • GET /api/providers/status · estado de proveedores IA
  • GET /api/export · backup completo JSON
  • POST /api/shutdown · cerrar servidor limpiamente

Tus datos

Tus sesiones, memoria, identidad y skills viven en:

  • Windows: %LOCALAPPDATA%\neuropa\
  • macOS / Linux: ~/.local/share/neuropa/

El desinstalador preserva esta carpeta. Si quieres migrar a otro equipo, copia esa carpeta y ya.

Backup completo

uv run neuropa --export backup-2026-08-07.json

Genera un JSON con todas tus entidades (sesiones, memoria, tareas, skills, identidad).

Desinstalar

Hay 4 niveles, de menos a más profundo:

  1. Solo NeuroPA · repo + cache uv. Datos preservados.
  2. + OpenCode · elimina también la CLI de IA gratuita.
  3. + Node.js · elimina también Node (afecta otras apps).
  4. + uv + Python · todo. Solo si estás seguro.

El desinstalador te pregunta qué nivel quieres en cada paso. Tus datos se mantienen hasta que confirmes explícitamente.

# Windows
neuropa-uninstall.bat

# macOS / Linux
bash neuropa-uninstall.sh

Solucionar problemas

"Este provider no expone modelos"

Si usabas un provider que decía esto, ya está corregido. La nueva versión detecta modelos con formato opencode/*. Si vuelve a aparecer, reinicia el servidor.

OpenCode no se detecta en Windows

npm instala OpenCode en %AppData%\npm\, que no está en PATH por defecto. Solución:

$env:PATH = "$env:USERPROFILE\AppData\Roaming\npm;$env:PATH"
[System.Environment]::SetEnvironmentVariable("NEUROPA_OPENCODE_BIN", "C:\Users\TU_USUARIO\AppData\Roaming\npm\opencode.cmd", "User")

El installer 2026-08-07 hace esto automáticamente.

Puerto 8474 ocupado

uv run neuropa --port 8475

Quiero empezar de cero

uv run neuropa --reset

Borra la base de datos local pero conserva tus exports.
